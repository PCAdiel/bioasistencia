# Demostración de portafolio

Esta página es un prototipo interactivo y autónomo con usuarios ficticios. No usa cámara, no trata información biométrica y no se conecta con Supabase; simula el registro de asistencia en el navegador.

Para publicarla en Vercel, importa el repositorio que contiene esta carpeta y configura **Root Directory** como `demo`. No requiere comando de instalación ni de compilación; `index.html` es el punto de entrada.

La aplicación completa de Bioasistencia está en su repositorio y requiere configurar Supabase y las funciones del proyecto para ejecutar el flujo biométrico académico.
